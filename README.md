# AI Agent 学习中枢 

这是为你（双非本硕 · 天津 · AI Agent / 大模型应用开发方向）定制的本地学习系统。
零第三方依赖，只用 Python 标准库 + 原生前端，启动一条命令。

---

## 一、快速开始

1. 确认电脑里有 Python 3.9+（命令行执行 `python --version` 能出结果）
2. **双击 `start.cmd`**（或在本目录执行 `python server.py`）
3. 浏览器会自动打开 `http://127.0.0.1:8787/`
4. 首次使用点右上角 **⚙️ 模型设置**：
   - 粘贴 API Key（本站已按阿里云百炼兼容模式预置好 Base URL 与 `deepseek-v4.1-flash`，直接点「保存」也行）
   - **思考强度保持「高」**（默认值）。实测该端点默认偏保守，本站会同时下发 `reasoning_effort` 与 `enable_thinking + thinking_budget`，把思考拉满
   - 点「测试连接」确认可用；想换模型点「拉取列表」从 200+ 个模型里挑（已按对话类优先排序）

> 不填 Key 也能用：路线图打卡、简历工坊、题库抽题全部可用，只有「问答对话」和「自动评分」会降级为离线模式。

停止服务：在命令行窗口按 `Ctrl + C`。

## 二、六个页面怎么用 + 多成员

### 1. 学习路线图
- 20 周逐周任务清单，点方块打勾，进度自动算到左侧进度环
- 每一周都有 **「学到什么程度」** 判定标准（这是防止你过度学习或学得不够的关键）
- 任务带难度标记：绿=基础 / 黄=进阶 / 红=深挖
- **每个任务右侧有「💡 教学」按钮**：一键跳到答疑窗口，让它按「是什么 → 具体命令 → 怎么验证 → 三个坑 → 过关标准 → 一道小练习」的结构手把手教你这一条，教完你可以继续追问
- 每周可填「实际小时」和「备注」（卡在哪、下周砍什么），这些会写进进度报告，方便我在 DSH 里读
- 「抗过时策略」「天津求职打法」两块是专门针对你两个顾虑写的，建议每月读一次

### 2. 简历工坊
- **左侧编辑，右侧实时 A4 预览**，点「导出 PDF」在弹出的打印窗口里选「另存为 PDF」
- **可上传证件照**：自动压缩到 420px 宽只存本机，渲染在简历**右上角**；支持更换/移除。透明背景自动转白，避免打印成黑块
- 两套版本一键切换：**AI Agent 版**（投 AI 应用/中小厂、无人机机器人公司）和 **控制/算法版**（投研究所、高校、无人机控制岗）
- 支持导出 **Markdown** 和 **LaTeX**（.tex 用 XeLaTeX 编译，含照片时会用 `\includegraphics` 排版，需自备同目录 `photo.jpg`）
- 模板里所有 `XX` 和 `{待填}` 都是占位符，右上角会统计还有多少处没填
- 写的时候记住一条：**每条要点都要有数字**（提升 %、延迟 s、成本 元、周期 h）

### 3. 模拟面试官
- 选择目标单位类型（可多选，第一个是主目标，决定通过率阈值）、难度上限、题量（10/20/30）
- 题库 124 题，按分类配额抽题，**练过的题会自动降权**，避免重复
- 逐题作答 → 提交 → 立刻给分、列出「你答到的要点 / 漏掉的要点 / 参考答案 / 面试官追问」
- 全部答完出报告：分类表现条、综合准备度（面试表现 75% + 路线图完成度 25%）、薄弱项、逐题复盘
- 「抽题设置」里可调各分类权重：投研究所就把「国企/研究所面」「项目追问」权重调高
- 三种题量对应三种压力：10 题热身、20 题标准、30 题压力面

> **关于「成功率」**：它是启发式估算（分类加权得分 → 按单位类型阈值做逻辑回归映射 → 与学习进度加权），不是真实录用概率。用途是判断「现在去面会怎样」和「先补哪里」。

### 4. 答疑与汇报
- **在线模式**（已填 Key）：直接对话。系统提示里已包含你的画像、电脑环境、20 周计划、当前进度、薄弱分类，**以及之前问过的问题的解答摘要**，所以它记得你、不用重复交代背景
- **粘贴看图**：`Ctrl+V` 直接粘贴截图（报错、别人的代码、论文插图），也可以拖拽图片或点 📎 上传，一次最多 4 张；会自动压缩到 1280px 再发送。实测主模型 `deepseek-v4.1-flash` 能准确读出截图内容并给出修复命令
- **教学插图（手动触发，不会自动跑）**：点「🎨 生成教学插图」才调用图像模型 `qwen-image-3.0-pro`（**这是唯一会产生额外图片额度的地方**），出图后自动存到本机 `state/images/`，不怕远端链接过期
- **免费示意图**：点「🖼️ 画示意图（SVG）」让主模型直接画 SVG 示意图（走普通对话额度、用低思考档省 token），可在页面里**下载成 PNG**
- **记忆档案（持久）**：见右侧面板，存在 `state/memory.json`，**清空对话 / 关闭网站 / 换浏览器都不会丢**
- **离线模式**：点右侧卡片按钮生成结构化文字 → 复制 → 粘到 DSH 对话里发给我
- 「把进度写回工作区」会把打卡、面试成绩与记忆档案写成 `../学习进度报告.md`，之后你在 DSH 里说「读一下我的学习进度报告」我就能直接看到

### 5. 长期记忆
- 独立一页，分 7 块：**当前机器（自动探测）· 学生画像（可编辑）· 名下设备（可编辑）· 环境补充说明（可编辑）· 长期备注 · 学习里程碑（自动累计）· 疑问解答记忆（可折叠）**
- **自动更新**：当前机器的 CPU/内存/GPU/磁盘/系统/Python/机型、**已装工具清单**（uv/git/node/docker/ollama/wsl/VS Code + 版本）、问答记忆（每次问答后）、学习里程碑（完成整周任务 / 保存一轮面试成绩后）；点右上角「🔄 重新探测环境与工具」可立即刷新，不必重启网站
- **手动维护**：画像、设备文字、环境补充说明、长期备注（与自动探测冲突时以自动探测为准）
- 探测不依赖启动时的 PATH：命令在 PATH 里找不到时会去 `%APPDATA%\Python\*\Scripts`、`~/.local/bin` 等目录兜底，并区分「✅ 在 PATH 里 / ⚠️ 装了但不在 PATH / ❌ 未检测到」

### 6. GitHub 热榜
- 四个时间窗口：**近七天 / 近一个月 / 近三个月 / 总榜**，各取 Top 20，页面会显示实际使用的查询语句
- 抓取口径：时间窗口用「**该时间段内新建 + star 最多**」（`created:>日期 stars:>=阈值`），这才是真正的"新晋热门"；总榜用 `stars:>50000`
- 可勾选 **只看 AI / Agent 相关**（追加 `llm OR agent OR rag OR mcp`）
- 每个项目给出：中文简介 + **推荐原因** + 右侧**推荐等级**与**推荐类型**
  - 等级（值不值得投入）：非常推荐 / 较为推荐 / 适中 / 不推荐
  - 类型（为什么推荐）：**学习相关**（对学习求职有帮助）/ **实用工具**（单纯好用、能提效）/ **视野扩展**（了解即可）/ **不相关**
  - 推荐原因的文字也强制以「学习价值：…」「实用价值：…」「视野扩展：…」「不推荐：…」开头，一眼能看出是哪种理由
- **「☆ 加入我的关注清单」**：把项目存进长期记忆（含等级、类型、推荐原因），可在「长期记忆」页管理、复制成 Markdown；答疑时也会带给模型，避免重复推荐你已在跟的项目
- **每天定时更新**：服务端后台线程每天到点自动抓取四个窗口 + AI 过滤窗口，并按设置生成分析。**进页面只读缓存，不会触发检索**——默认每天 08:00、只分析近七天（省额度），可在页面上改时间与范围，或点「⚡ 立即更新一次」
- **网站关着也想更新**：用独立脚本 `python update_trending.py`（加 `--no-analyze` 则只抓数据不花额度），可配合 Windows 计划任务实现真正的全自动（脚本注释里有现成的 schtasks 命令）
- 未配置模型 Key 时自动降级为**规则打分**（关键词 + 语言 + star）
- GitHub 未登录时搜索接口限 10 次/小时；在「设置 → 高级」填 GitHub Token 可提到 30 次/分

### 0. 多成员（两个人怎么一起用）

- **首次打开会让你选成员**：可以选已有成员（主账号，也就是你），或直接填名字新建一位（例如你女朋友）
- **右上角显示当前成员**，点它就能切换 / 新增成员 / 管理成员；切换后**整页按新成员的数据重新加载**
- **数据完全隔离**：学习进度打卡、长期记忆与画像、关注清单、简历、面试记录、问答记忆、里程碑、待办队列，**每位成员各一份**，互不影响；切换过去可以查看对方的全部信息
- **首次进入新成员会弹出画像问卷（17 题）**：称呼、身份与学校类型、研究方向、求职目标与岗位方向、毕业与投递节点、每周可投入时间、编程基础、数学与算法基础、常用工具、电脑配置、优势、短板、当前困扰、学习偏好、必须记住的事。答案会写进该成员的长期记忆，之后答疑、热榜推荐、面试评分都按 TA 的情况来；随时可在右上角菜单「重新填写/修改我的画像」或在「长期记忆」页改
- **机器环境是全局的**：自动探测的是「当前这台电脑」，两人共用一份（你俩都在工位用同一台电脑时这更准确）；**名下设备**由各自的画像填写（她可以写自己的笔记本）
- 服务端按 `state/users/<成员>/` 分目录存放，报告分别写成 `学习进度报告.md`（主账号，供 DSH 读取）与 `学习进度报告-<名字>.md`
- 成员管理支持删除（主账号不可删），删除会连同其数据目录一起清理

### 0.1 两个人怎么一起用（同一份数据 / 局域网共享）

> **关键：`127.0.0.1` 是"回环地址"，永远指向打开网页的那台电脑。** 别人的电脑上用这个网址一定连不上（`ERR_CONNECTION_REFUSED`）。

**方式一：局域网共享（推荐，数据同一份、可互相查看）**

1. 在**服务端这台电脑**上双击 **`start-lan.cmd`**（等价于 `python server.py --lan`）
2. 控制台会打印出两行链接，例如：
   ```
   本机打开：http://127.0.0.1:8787/?k=xxxxxxxxxxx
   ★ 让别人的电脑访问：http://192.168.3.5:8787/?k=xxxxxxxxxxx
   ```
3. 把**局域网那条链接**发给她，她在自己电脑上打开即可（需在同一个 WiFi / 同一个办公网）
4. 如果她打不开 → 十有八九是 **Windows 防火墙**：
   - 简单办法：在服务端电脑上重新双击 `start-lan.cmd`，Windows 弹「允许 python 访问网络」时点**允许**
   - 或者：右键「以管理员身份运行」PowerShell，执行
     ```
     netsh advfirewall firewall add rule name="agent-hub" dir=in action=allow protocol=TCP localport=8787
     ```

**`?k=` 那串令牌是什么**：共享模式下所有 `/api/*` 都要校验它（保存在 `state/lan-token.txt`），防止同一个网段的同事随手打开你的网站、蹭掉你的模型额度。**首次访问链接里带 `?k=` 后浏览器会记住**，之后直接开 `http://192.168.3.5:8787/` 也能用。不想要令牌就加 `--no-token`（不建议）。

**方式二：各用各的（数据互不可见）**

把整个 `ai-agent-hub` 目录拷到她的电脑上，在她那边双击 `start.cmd`，她自己建成员、填画像。缺点：两份数据完全独立，你看不到她的进度（方式一才能互相查看）。

**两种模式的对比**

| | 局域网共享（--lan） | 各拷一份 |
| --- | --- | --- |
| 数据 | 同一份，右上角可切换查看对方 | 各一份，互不可见 |
| 她的网址 | `http://<你的IP>:8787/?k=令牌` | 她自己的 `http://127.0.0.1:8787/` |
| 你关机后 | 她也用不了 | 她照常用 |
| 模型额度 | 共用你的 Key | 各自配 Key |

### 0.2 启动方式（**已取消开机自启**）

**现在不会开机自动启动，也不会自动弹浏览器。** 需要用时手动双击一次。

| 想干什么 | 双击哪个 |
| --- | --- |
| 自己用（只有本机能开） | `start.cmd` |
| 局域网共享（同学也能开） | `start-lan.cmd` |
| 后台隐藏跑（没有黑窗口） | `start-hidden.vbs` |
| 停掉服务 | `stop-hub.cmd` |

启动后要自己打开浏览器访问（第一次可以看 `state/access-links.txt` 里现成的链接）：

- 本机：`http://127.0.0.1:8787/?k=<令牌>`
- 局域网：`http://<你的IP>:8787/?k=<令牌>`

**为什么改成手动启动**：开机自启配合「自动弹浏览器」每天都会多出一个窗口，
而且 IP 变化后旧链接本来就失效，每次都要重新看一眼地址，自启省不了事。

**几个要知道的点**：

| 情况 | 表现 | 处理 |
| --- | --- | --- |
| 关机后再开机 | **不会自己起来** | 双击 `start-hidden.vbs`（或 `start-lan.cmd`） |
| 想让同学访问 | 必须先在本机启动服务 | 双击 `start-lan.cmd`，把 `access-links.txt` 里的局域网链接发她 |
| 电脑**睡眠 / 休眠** | 服务还在，但网络断开，别人连不上 | 唤醒即可 |
| 换了 WiFi / 网络 | **局域网 IP 会变**，旧链接失效 | 重启服务，看 `access-links.txt` 更新后的地址 |
| 想临时停掉 | — | 双击 `stop-hub.cmd` |
| 想恢复开机自启 | — | 把 `手动启动-局域网.lnk` 复制回启动文件夹 |

> 启动脚本里判断「端口已在跑就跳过」，所以重复双击不会端口冲突。

**关于自动开浏览器**：默认**不打开**。真要它开，加参数 `--browser`：
`python server.py --lan --browser`（`--no-browser` 保留兼容，等同于默认行为）。

> **记忆档案说明**：网站启动时会自动探测你的电脑环境（CPU、内存、磁盘、Python 版本、系统版本，GPU 型号从 nvidia-smi 读取），与你的画像、长期备注、每次问答的解答摘要一起写入 `state/memory.json`。每次提问都会把这份档案带进模型上下文，因此**清空对话、关闭网站、重启电脑、换浏览器都不会失忆**。你可以在「答疑与汇报」右侧面板里增删备注、单独清空问答记忆，或重置整个档案。

## 四、常见问题

**Q：浏览器提示「未检测到本地服务」？**
说明你是直接双击 index.html 打开的。用 `start.cmd` 启动服务后再访问 `http://127.0.0.1:8787/`，否则进度不会写回文件，也不能自动评分。

**Q：端口 8787 被占用？**
`python server.py --port 9000`，然后访问 `http://127.0.0.1:9000/`。

**Q：导出 PDF 时格式乱了？**
打印窗口里纸张选 **A4**、边距选**默认**、勾选**背景图形**（否则灰色区块不显示）。预览区是标准 A4 宽度，所见即所得。

**Q：评分结果不准？**
在线模式由模型按「评分要点」判定；离线模式是关键词比对（偏宽松），提交后可以用「自行修正」按钮调整分数。

**Q：想改学习计划或题库？**
- 改计划：编辑 `data/roadmap.data.js`
- 加题：往 `data/questions/*.json` 里追加同结构对象（字段见任一现有题目），然后刷新页面

**Q：API Key 安全吗？**
只写在本机 `state/settings.json`，请求由你本机的 `server.py` 转发到 DeepSeek，不经过任何第三方。`state/` 目录不要提交到 Git。
